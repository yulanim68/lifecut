# 확장 B: 사진 필터 고르기

## 목표

결과 화면에서 원본, 흑백, 세피아, 따뜻하게, 시원하게, 화사하게 중 하나를 골라 완성 사진을 바로 바꿔 볼 수 있게 합니다. 필터 효과는 촬영 사진에만 적용하고, 세로 프레임의 바탕과 글씨는 그대로 유지합니다. 원본으로 돌아갈 수 있어야 하며, 필터를 바꿀 때마다 필터가 누적되지 않도록 원본 촬영 사진에서 새 결과를 만듭니다.

## 사용자 이야기

완성한 인생네컷을 확인하는 사용자는 여러 분위기의 필터를 눌러 보며 결과를 비교하고 싶습니다. 선택한 효과가 즉시 적용되어야 하며, 언제든 원본을 다시 선택해 촬영 그대로의 사진을 볼 수 있어야 합니다.

## 화면 흐름

1. 촬영을 마친 사용자가 결과 화면에 들어옵니다. 처음에는 필터를 적용하지 않은 원본 결과를 보여 줍니다.
2. `필터를 골라 보세요` 안내 아래, 결과 프레임 위에 준비된 필터 목록 위치에 JavaScript로 만든 버튼 6개를 보여 줍니다.
3. 버튼 이름은 `원본`, `흑백`, `세피아`, `따뜻하게`, `시원하게`, `화사하게`입니다.
4. 사용자가 버튼을 누르면 별도의 적용 버튼 없이 완성 사진의 촬영 사진들에 선택한 필터가 즉시 적용됩니다.
5. 프레임 바탕과 `인생네컷`, 날짜 등의 글씨는 필터 효과를 받지 않고 그대로 유지됩니다.
6. 다른 필터를 누르면 직전에 필터를 적용한 결과를 다시 바꾸는 대신, 원본 촬영 사진에서 선택한 필터를 적용한 새 결과를 만듭니다. `원본`을 누르면 필터 효과가 없는 원래 결과로 돌아갑니다.
7. 필터를 바꿔도 결과 프레임의 크기와 사진 해상도를 낮추지 않아 원본 화질을 유지합니다.

## 완료 기준 체크리스트

- [ ] 결과 화면에 `필터를 골라 보세요` 안내가 보이는가? (예/아니오)
- [ ] 안내 아래 필터 목록 위치에 JavaScript로 만든 `원본`, `흑백`, `세피아`, `따뜻하게`, `시원하게`, `화사하게` 버튼이 모두 보이는가? (예/아니오)
- [ ] 결과 화면에 처음 들어왔을 때 필터 효과가 없는 원본 결과가 보이는가? (예/아니오)
- [ ] 필터 버튼을 누르면 별도의 적용 버튼 없이 결과 사진이 즉시 바뀌는가? (예/아니오)
- [ ] 선택한 필터가 완성 프레임의 촬영 사진들에 적용되는가? (예/아니오)
- [ ] 필터를 바꿔도 프레임 바탕과 프레임의 글씨가 원래 모습 그대로인가? (예/아니오)
- [ ] 필터를 연달아 바꾸어도 효과가 누적되지 않고, 매번 원본 촬영 사진에서 새 결과를 만드는가? (예/아니오)
- [ ] `원본` 버튼을 누르면 필터 효과가 없는 원래 사진 결과로 돌아가는가? (예/아니오)
- [ ] 필터를 바꾸어도 결과 프레임 크기와 사진 해상도가 낮아지지 않아 원본 화질이 유지되는가? (예/아니오)
