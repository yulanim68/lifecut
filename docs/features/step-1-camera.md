# 1단계: 사진 한 장 촬영하고 확인하기

## 목표

사용자가 카메라 화면을 보며 촬영 버튼을 누르고, 5초를 센 뒤 찍힌 사진 한 장을 확인할 수 있게 합니다. 휴대폰 세로 화면에서 쓰기 쉽게 만들고, 다른 화면 크기에서도 사용할 수 있게 합니다.

## 사용자 이야기

카메라로 촬영할 때, 사용자는 촬영 전에 준비할 시간을 갖고 싶습니다. 촬영 버튼을 누르면 5초 카운트다운(남은 시간을 숫자로 세어 보여 주는 것)이 진행되고, 촬영이 끝나면 찍힌 사진을 화면에서 확인할 수 있습니다.

## 화면 흐름

1. 페이지를 열면 카메라 사용을 요청하고, 허용되면 실시간 카메라 화면을 보여 줍니다.
2. 사용자가 촬영 버튼을 누릅니다.
3. 화면에 5부터 1까지 차례로 표시합니다. 카운트다운이 끝날 때까지 촬영 버튼을 다시 누를 수 없습니다.
4. 카운트다운이 끝나면 사진 한 장을 촬영합니다.
5. 촬영된 사진을 화면에 보여 주어 사용자가 결과를 확인합니다.
6. 카메라를 사용할 수 없거나 사용자가 권한을 허용하지 않은 경우, 문제와 해결 방법을 쉬운 문장으로 안내합니다.

## 완료 기준 체크리스트

- [ ] 페이지를 열고 카메라 사용을 허용하면 실시간 카메라 화면이 보이는가? (예/아니오)
- [ ] 촬영 버튼을 누르면 5, 4, 3, 2, 1 순서로 화면에 표시되는가? (예/아니오)
- [ ] 카운트다운이 끝난 뒤 사진 한 장이 촬영되는가? (예/아니오)
- [ ] 촬영이 끝나면 실제로 찍힌 사진이 화면에 보이는가? (예/아니오)
- [ ] 카운트다운 중에는 촬영 버튼을 다시 눌러 추가 촬영을 시작할 수 없는가? (예/아니오)
- [ ] 카메라를 사용할 수 없거나 권한이 거부된 경우, 사용자가 다음에 할 일을 알 수 있는 안내가 보이는가? (예/아니오)
- [ ] 화면이 휴대폰 세로 화면과 일반적인 데스크톱 화면에서 잘리지 않고 사용할 수 있는가? (예/아니오)
- [ ] 1단계 기능 코드가 `index.html`, `style.css`, `js/app.js` 안에만 있는가? (예/아니오)
- [ ] 1단계에서 별도 `js/camera.js` 파일을 만들지 않았는가? (예/아니오)

## 이번에 하지 않을 것

- 여러 컷 촬영, 2컷/4컷 선택, 사진을 세로 프레임 한 장으로 합치기
- 사진 필터 적용
- 사진 온라인 보관, Supabase 연결, QR 코드로 사진 받기
- 카운트다운 소리, 꾸미기 효과 등 추가 촬영 기능
- `js/camera.js`로 카메라 기능을 분리하기: 이 파일 분리는 확장 A에서 다룹니다. 1단계에서는 필요한 카메라 동작을 `js/app.js`에 둡니다.
