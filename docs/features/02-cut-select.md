# 확장 A: 컷 수 선택, 자동 촬영과 세로 프레임

## 목표

사용자가 2컷 또는 4컷을 선택하고 시작 버튼을 한 번 누르면, 각 컷을 5초 카운트다운 뒤 자동으로 촬영합니다. 촬영 진행과 이미 찍은 사진을 확인하고, 모든 컷이 끝나면 사진을 세로 프레임 한 장으로 확인할 수 있게 합니다.

## 사용자 이야기

사진을 여러 장 연달아 찍고 싶은 사용자는 촬영을 매번 다시 시작하지 않고, 원하는 컷 수를 골라 한 번에 촬영을 마치고 싶습니다. 촬영 중에는 몇 번째 컷인지와 이미 찍은 사진을 확인하고, 마지막에는 촬영 순서대로 정리된 결과를 보고 처음부터 다시 선택할 수 있습니다.

## 화면 흐름

### ① 컷 선택

1. 화면에 작은 세로 프레임 그림이 있는 `2컷` 버튼과 `4컷` 버튼을 보여 줍니다.
2. 사용자가 한 가지 컷 수를 선택하고 시작 버튼을 한 번 누릅니다.
3. 선택한 컷 수와 관계없이 촬영을 시작하는 버튼은 한 번만 누르면 됩니다.

### ② 촬영

1. 선택한 컷 수만큼 촬영을 이어서 진행합니다.
2. 각 컷마다 5초 카운트다운을 보여 준 뒤 사진 한 장을 촬영합니다.
3. 촬영 중 현재 진행 상황을 `현재 컷 번호 / 선택한 컷 수` 형식으로 보여 줍니다. 예: `1 / 4`.
4. 촬영된 사진은 작은 미리보기로 보여 줍니다. 다음 컷이 남아 있으면 촬영 사이에 0.7초 쉬고 다음 5초 카운트다운을 시작합니다.
5. 선택한 컷 수만큼 촬영을 마치면 결과 화면으로 이동합니다.

### ③ 결과

1. 흰 바탕 위에 세로 프레임 한 장을 보여 줍니다.
2. 사진은 각각 4:3 비율로, 촬영한 순서대로 위에서 아래로 쌓아 배치합니다.
3. 프레임 맨 아래에 `인생네컷`과 오늘 날짜를 표시합니다.
4. `처음으로` 버튼을 누르면 컷 선택 화면으로 돌아갑니다.

## 최소 정의 및 미정 사항

- 카운트다운은 1단계와 같은 방식으로 `5, 4, 3, 2, 1`을 차례로 표시하는 것을 기본 정의로 합니다.
- 0.7초 쉬기는 한 컷 촬영이 끝난 뒤 다음 컷의 카운트다운이 시작되기 전의 간격입니다. 마지막 컷 뒤에는 다음 촬영이 없으므로 쉬는 시간을 두지 않습니다.
- 날짜는 결과를 만드는 기기의 오늘 날짜를 사용합니다. 날짜 표기 형식은 별도 지정이 없으므로 구현 전 확인 대상이며, 임의로 고정하지 않습니다.
- 촬영 사진을 4:3 칸에 맞추는 방법(사진 일부 자르기 또는 전체 사진 표시)은 지정되지 않았으므로 구현 전 확인 대상입니다.
- 카메라 권한 거부나 촬영 오류 때의 재시도 동작은 지정되지 않았습니다. 오류와 사용자가 취할 다음 행동을 안내하는 것을 최소 기준으로 하며, 복구 방식은 임의로 추가하지 않습니다.
- `처음으로`를 눌렀을 때 이전 선택이나 촬영 사진을 보존할지는 지정되지 않았습니다. 화면은 컷 선택으로 돌아가며, 새 촬영은 새 선택으로 시작하는 것을 최소 정의로 합니다.
